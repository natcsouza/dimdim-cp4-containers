Solução entregue

API REST em Java 17 com Spring Boot 3 para cadastro de clientes, e banco MySQL 8.0, ambos conteinerizados. As imagens foram publicadas no Azure Container Registry e executam como Azure Container Instances, com os dados do banco persistidos num Azure File Share da Conta de Armazenamento. Todos os recursos foram criados por Azure CLI.
