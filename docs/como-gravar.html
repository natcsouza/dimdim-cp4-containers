Como gravar o vídeo

Tudo pelo navegador, sem instalar nada no computador.

A ideia: você vai usar o Azure Cloud Shell — um terminal que roda dentro do site da Azure. Ele já vem conectado na sua conta e já tem tudo que o script precisa. Você só lê o que aparecer na tela e aperta ENTER.

Antes de ligar a gravação

1. Abra o portal da Azure
Entre em portal.azure.com com o seu login da FIAP (RM564099@fiap.com.br).
2. Abra o Cloud Shell
No topo da tela, clique no ícone >_ (fica perto do sininho de notificações). Se ele perguntar, escolha Bash.

Na primeira vez ele pergunta sobre armazenamento — pode escolher a opção mais simples, qualquer uma serve.
3. Baixe o projeto
Cole este comando e aperte ENTER:
git clone https://github.com/natcsouza/dimdim-cp4-containers.git cd dimdim-cp4-containers
4. Informe a senha do banco
export DB_PASSWORD='<a senha que o Dolglas te passou>'
Faça o passo 4 com a gravação DESLIGADA. Se a senha aparecer na tela durante o vídeo, são 20 pontos a menos por expor dado sensível. Depois de digitar, limpe a tela com o comando clear.
5. Teste antes
Rode o script uma vez, só para conferir que está tudo certo:
bash gravar-video.sh
Ele vai mostrar uma lista de conferência. Se aparecer tudo com v verde, pode fechar (Ctrl+C) — está pronto para gravar de verdade.

Agora sim: gravando

6. Aumente a fonte do terminal
Aperte Ctrl e + uma 3 vezes. O professor precisa conseguir ler.
7. Ligue a gravação
Grave em 720p ou mais, com o microfone ligado. Feche abas com coisa pessoal antes.
8. Rode o script e siga
bash gravar-video.sh
A partir daqui é só repetir:
  • aparece um texto amarelo na tela → leia em voz alta
  • aperte ENTER → o comando roda sozinho
  • aperte ENTER de novo → vai para o próximo
São 10 passos. Você não precisa decorar nem digitar nada.
Se errar a fala: não tem problema. Aperte Ctrl+C, rode bash gravar-video.sh de novo e recomece. Pode repetir quantas vezes quiser.

O que o vídeo vai mostrar

PassoO que aparece
1 e 2Os recursos criados na Azure e os dois containers rodando
3As duas imagens no Container Registry, com seu RM no nome
4A prova de que a aplicação não roda como root
5Estado inicial do banco: dois clientes
6CREATE — insere um cliente, e o SELECT mostra ele no banco
7READ — busca esse cliente pela API
8UPDATE — muda e-mail e saldo, e o SELECT confirma
9DELETE — remove, e o SELECT mostra que sumiu
10Fechamento
Os SELECTs são o que mais vale nota — 30 pontos. Não corte essas telas e não tenha pressa nelas.

Depois de gravar

9. Suba no YouTube
Na hora de publicar, escolha "Não listado".
Não escolha "Privado". Se ficar privado, o professor não consegue abrir o vídeo — e sem acesso ao vídeo a prova vale zero.
10. Mande o link
Copie o link do YouTube e mande. Ele entra na folha de rosto, e aí o PataCloud_container.pdf fica pronto para subir no Teams.
